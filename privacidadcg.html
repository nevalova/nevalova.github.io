Crazy Gears

Política de privacidad

Última actualización: 17 de noviembre de 2026

Esta política explica cómo se trata la información en Crazy Gears para Android (com.thatmexicangamecompany.crazygears). That Mexican Game Company es responsable del juego.

Datos que permanecen en el dispositivo

El juego guarda los récords personales, tus preferencias de idioma, sonido y controles, y un contador local de derrotas para espaciar los anuncios. No requiere una cuenta de juego ni envía esos récords a servidores propios. Puedes borrar estos datos desde los ajustes de almacenamiento de Android. Si Android restaura una copia de seguridad, algunos datos locales pueden recuperarse.

Publicidad de Google AdMob

Crazy Gears utiliza el SDK de Google Mobile Ads para mostrar anuncios intersticiales entre partidas. El SDK puede recopilar y compartir los siguientes datos para mostrar y medir anuncios, analizar el funcionamiento del SDK y prevenir fraude.

  • Dirección IP, que puede utilizarse para estimar la ubicación aproximada del dispositivo.
  • Interacciones con la aplicación o con anuncios, como aperturas, toques y visualizaciones.
  • Información de diagnóstico y rendimiento de la aplicación y del SDK.
  • Identificadores del dispositivo, como el identificador publicitario de Android, el identificador del conjunto de aplicaciones y otros identificadores aplicables.

Según Google, el SDK cifra estos datos en tránsito. Puedes consultar la divulgación de datos de AdMob y la Política de Privacidad de Google para conocer el tratamiento y los controles disponibles.

Controles y conservación

Puedes gestionar o eliminar el identificador publicitario desde los ajustes de privacidad de Android, según la versión de tu dispositivo. Los datos locales del juego se conservan hasta que se eliminan del dispositivo. Para la información que trata Google, aplica su propia política de privacidad.

Soporte y solicitudes de privacidad

Si nos escribes, utilizamos tu correo y el contenido de tu mensaje para responder. Conservamos la conversación mientras sea necesaria para atender la consulta o cumplir las obligaciones aplicables. Puedes solicitar acceso, corrección o eliminación de los datos de soporte escribiendo a soporte@thatmexicangamecompany.mx.

Este sitio web

Esta página no contiene formularios ni publicidad. GitHub Pages aloja el sitio y puede procesar información técnica de las visitas para prestar su servicio. Consulta la Declaración de Privacidad de GitHub.
